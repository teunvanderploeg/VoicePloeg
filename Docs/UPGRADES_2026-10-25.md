# VoicePloeg upgrade implementation

The upgrades apply to commit `7e5a322`, which rolled back experimental live dictation. That rollback remains intact. The October review describes the earlier live implementation too, so its live-only segmentation and editor polling proposals do not apply to this version.

## Completed changes

| Area | Result |
| --- | --- |
| Language selection | Whisper receives `-l auto` explicitly. Auto has an independent multilingual model assignment. English-only models reject Auto. Existing explicit-language assignments remain available. |
| Shortcut handling | Registration replaces the old shortcut only after the new one succeeds. Failed changes preserve the previous preference. Reserved combinations are rejected, Escape cancels recording a shortcut, and printable key labels use the keyboard layout. Configuration errors cannot overwrite dictation state. |
| Readiness | Installed files, integrity metadata, executable availability, permissions, and backend preparation are checked before capture. Recording never starts a download. |
| Transcription recovery | One failed recording can remain in memory for Retry or Discard. Retry exposes recovered text for copying and respects history retention without pasting into a stale editor. Successful recognition clears retained audio before insertion. |
| Input lifecycle | Preferences use device UIDs. A restoration journal tracks VoicePloeg's system input change and preserves external changes. Device loss and engine reconfiguration stop capture and retain recoverable audio. Quit coordinates capture, route restoration, worker release, and pending clipboard cleanup. |
| Process lifecycle | Subprocesses launch in owned process groups. Cancellation and timeout kill ordinary descendants and join the launcher before removing temporary files. Worker shutdown permits bounded graceful exit after acknowledgement. |
| Installation integrity | Snapshot status validates identity and required nonempty files. Readiness verifies JSON and safetensors structure. New installs record per-file sizes and SHA-256 hashes. Crisper loads the snapshot offline before publication. |
| Runtime repair | A shared installer creates relocatable candidate environments, validates imports before and after publication, and preserves a backup for rollback or interrupted-publication recovery. Apple Silicon installer packaging also works from an Intel build host. |
| Model preparation | Maintenance cancels and joins obsolete preparation. Preparation failures are visible. Current selection warms after recording; idle workers unload after ten minutes. Memory-pressure release excludes concurrent recording and maintenance. |
| Audio | Peak normalization has a maximum gain of 16 and handles nonfinite samples. WAV serialization handles nonfinite input. Temporary audio and log directories are restricted to their owner. |
| Settings and history | Download controls describe downloading. Settings show readiness and separate preparation/transcription/delivery timings. History supports Off, 7 days, 30 days, Until cleared, persistent per-entry deletion, and clearing the current transcript with history. Permissions refresh on activation. |
| Build and release | Both build paths use Swift 6. Semantic catalog validation checks hashes, sizes, unique IDs and capabilities. A macOS GitHub workflow runs the release preflight. Regression tests cover the new behavior. |

## Recognition checks

Final release preflight passed the standard build, strict concurrency build with warnings as errors, all 121 Swift tests with two opt-in tests skipped and no failures, all 17 Python tests, catalog validation, project generation, and unsigned Xcode Release packaging. Both opt-in tests were also run explicitly: the recognition corpus against installed backends, and twelve alternating model-load cancellations followed by successful loads of Bark Standard and Crisper medium. `git diff --check` passed.

The opt-in corpus test ran against already installed Whisper base multilingual, Bark Standard and Crisper medium, without recording or downloading. It compared raw, normalized and quiet-normalized audio using the English JFK fixture and a locally generated Dutch fixture.

Whisper Auto recognized the Dutch fixture with zero normalized word error across those three variants. Crisper's explicit Dutch transcription had one word error out of twenty-two words. All three backends matched the English reference words across the tested variants. These are small integration fixtures, including synthetic speech, and do not establish accuracy on everyday recordings.

The worker shutdown run completed without the leaked-semaphore warning seen during the earlier review. A regression worker also verifies that cleanup after a shutdown acknowledgement completes before the client returns.

The Dutch fixture in `Tests/Fixtures/synthetic-dutch.wav` was generated locally with macOS Xander on 25 October 2026. The reference sentence is in `dictation-corpus.example.json`. Its 16 kHz mono WAV contains no user recording. See `Docs/QA.md` for running the corpus and adding representative recordings.

## Remaining validation and experiments

- Test microphone disconnects, external system-input changes, and Quit using real audio devices and the exact distributed app identity. Unit tests exercise route ownership and UID restoration, but do not replace hardware checks.
- Validate Developer ID signing, notarization, and clipboard delivery in target applications on a clean machine before release.
- Existing snapshot installations without per-file hashes remain compatible after structural checks. Repairing a model writes the stronger manifest. New installation health checks and rollback have automated coverage; a full package/model reinstall over the network was not performed during these upgrades.
- The CI workflow is added; it has not been run on GitHub in this session.
- Input routing remains system-wide. App-scoped capture routing needs a hardware feasibility test.
- The one-second clipboard delivery lifetime remains. The current stop-and-transcribe app does not have live editor confirmation that would justify shortening it.
- A persistent Whisper helper, adaptive VAD, live segmentation, and recognition policy changes require separate measurements or a future live-dictation decision. The default backend and model quality ranking were not changed.
